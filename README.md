# Restora Sleep

A static, responsive sleep wellness website built with HTML, CSS and vanilla JavaScript.

## Included
- Homepage
- Sleep cycle calculator (wake-up and bedtime modes)
- Sleep quality reflection quiz
- Chronotype preference quiz
- Daily sleep tracker with local browser storage and CSV export
- Blog index and three original starter articles
- About, Contact, Privacy Policy, Disclaimer and Terms pages
- SEO starter metadata, robots.txt, sitemap.xml and ads.txt placeholder
- Netlify-ready contact form and configuration

## Deploy
### Netlify
1. Extract the ZIP.
2. Replace `YOUR-DOMAIN.example` in canonical URLs, `robots.txt` and `sitemap.xml` with your real HTTPS domain.
3. Review and customize About, Contact and legal pages. Add your real contact details and editorial author information.
4. Push the folder to a GitHub repository.
5. In Netlify choose **Add new site → Import an existing project**, connect GitHub and select this repository.
6. Set the publish directory to `.` and leave build command blank.
7. Deploy. Netlify Forms can process the contact form after form detection is enabled and a new deploy is completed.

### Traditional hosting
Upload all files and folders to the public web root (often `public_html`). Keep the folder structure intact.

## AdSense preparation
- Ad slots are labeled placeholders; no ads are served until you add valid ad code.
- After approval, add the exact AdSense code supplied in your account and the correct publisher line to `ads.txt`.
- Replace placeholder domain values and submit the sitemap in Search Console.
- Review all content, citations, legal disclosures, cookie/consent requirements and contact details before applying.
- Approval is not guaranteed. This starter project is not a substitute for a complete editorial and policy review.

## Important content notes
The sleep cycle calculator uses an adjustable assumed cycle length. It does not measure sleep stages or guarantee improved alertness. Do not make medical claims or publish invented author credentials, testimonials or personal experience.
